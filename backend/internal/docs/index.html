MockHub · 在线 API Mock 服务 API 文档

Go 1.22 + Gin + GORM · OpenAPI: /docs/openapi.json

认证

方法路径说明
POST/api/v1/auth/register注册账号（username + password）
POST/api/v1/auth/login登录，返回 JWT token 与用户信息
GET/api/v1/auth/me获取当前登录用户（需 Bearer token）

Mock 项目

方法路径说明
GET/api/v1/projects项目列表
POST/api/v1/projects创建项目
GET/api/v1/projects/:id项目详情
PUT/api/v1/projects/:id更新项目
DELETE/api/v1/projects/:id删除项目

Mock 接口配置

方法路径说明
GET/api/v1/projects/:projectId/apis接口列表
POST/api/v1/projects/:projectId/apis新建接口
PUT/api/v1/projects/:projectId/apis/:id更新接口
DELETE/api/v1/projects/:projectId/apis/:id删除接口
POST/api/v1/projects/:projectId/swagger/import导入 OpenAPI 文档自动生成接口

请求日志

方法路径说明
GET/api/v1/projects/:projectId/logs分页查看请求日志
DELETE/api/v1/projects/:projectId/logs清空请求日志

公开 Mock 引擎

方法路径说明
ANY/mock/:projectId/*path发送 Mock 请求（动态/条件响应、延迟模拟）
GET/healthz健康检查
